## Цель
Применить K-Means, подобрать число кластеров и сравнить три алгоритма на данных сложной формы.

## Запуск в VS Code

Открыть папку проекта через File → Open Folder, затем Terminal → New Terminal.

```bash
python -m pip install -r requirements.txt
python main.py
```

В Ubuntu вместо `python` можно использовать `python3`. При необходимости создать виртуальное окружение `python3 -m venv .venv`, активировать его командой `source .venv/bin/activate` (Linux) или `.venv\Scripts\activate` (Windows PowerShell).

Исходный шаблон и датасет не приложены, поэтому используются синтетические данные с фиксированным seed 42: 400 клиентов и 500 точек в форме двух полумесяцев. Для A принято k=3 как демонстрационное значение. Все данные и результаты уже включены; повторный запуск их воспроизводит.

## Вариант C

Для сравнения трёх подходов использован `make_moons`: два невыпуклых полумесяца с шумом 0.045. Метки генератора используются только для оценки, а не обучения.

![Исходные данные](results/C_data.png)

K-Means (k=2) разделяет точки по расстоянию до центроидов и не восстанавливает форму полумесяцев.

![K-Means](results/C_KMeans.png)

DBSCAN (eps=0.23, min_samples=5) объединяет точки по плотности и восстанавливает обе группы.

![DBSCAN](results/C_DBSCAN.png)

Агломеративная кластеризация (single linkage, k=2) объединяет ближайшие группы и также восстанавливает полумесяцы.

![Agglomerative](results/C_Agglomerative.png)

| Алгоритм | Кластеры | Шум | Силуэт | ARI |
|---|---:|---:|---:|---:|
| K-Means | 2 | 0 | 0.4966 | 0.4559 |
| DBSCAN | 2 | 0 | 0.3901 | 1.0000 |
| Agglomerative | 2 | 0 | 0.3901 | 1.0000 |

Силуэт выше у K-Means, поскольку он предпочитает компактные группы; здесь эта метрика не отражает правильность восстановления невыпуклой формы. ARI сравнивает результат с известными метками генератора. DBSCAN и Agglomerative восстановили исходные группы полностью. Выбираю DBSCAN для этой задачи: он не требует заранее задавать число кластеров и умеет выделять шум. При сильно различающейся плотности его параметры могут потребовать дополнительной настройки.

## Общий вывод
K-Means подходит для компактных клиентских сегментов. Для демонстрационных данных оптимальным оказалось k=4. На невыпуклых данных предпочтительны методы, учитывающие локальную структуру. Все результаты получены запуском `main.py` в Python.
